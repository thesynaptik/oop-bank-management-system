# OOP Bank Management System

A Bank Management System developed in Python using Object-Oriented Programming (OOP) principles. The project demonstrates core banking operations such as account creation, deposits, withdrawals, transfers, and account management through a structured and reusable design.

## Features

- Create and manage bank accounts
- Deposit and withdraw funds
- Transfer money between accounts
- View account details and balances
- Object-Oriented design with multiple classes
- User-friendly graphical interface

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Tkinter (GUI)

## Project Structure

```text
oop-bank-management-system/
│
├── bank_system.py   # Core banking logic
├── gui.py           # Graphical User Interface
└── README.md
```

## OOP Concepts Demonstrated

- Classes and Objects
- Encapsulation
- Inheritance
- Method Overriding
- Abstraction
- Code Reusability

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/thesynaptik/oop-bank-management-system.git
```

2. Navigate to the project folder:

```bash
cd oop-bank-management-system
```

3. Run the application:

```bash
python gui.py
```
